2D GauSS-MI — 2DGS 위에 올린 능동 장면 재구성

2D GauSS-MI: Efficient Active Scene Reconstruction with Balanced Visual and Geometric Quality
Yuhan Xie, Jia Pan (University of Hong Kong) · arXiv 2609.21516, 2026-09-18 · arXiv · 코드는 "게재 확정 시 공개" 예정(링크 미공개)

TL;DR

쿼드로터가 실내 장면을 스스로 돌아다니며 찍을 다음 시점(next-best-view, NBV)을 고르는 능동 재구성(active reconstruction) 시스템이다. 지도 표현으로 2D Gaussian Splatting(2DGS) 을 쓴 첫 능동 재구성 시스템임을 주장하며, 2D Gaussian 하나하나에 법선 기준 앞면/뒷면 두 개의 베이즈 신뢰도(two-sided reliability) 를 붙이고, 그 신뢰도로 Shannon 상호정보량 2D GauSS-MI 를 계산해 후보 시점을 평가한다. Replica 8장면에서 PSNR 36.87 / Depth-L1 0.25 cm / F-score 0.970 을 내면서, 후보 시점 1개 평가에 1.01 ms(990.6 fps) 만 쓴다 — 선행 GauSS-MI(5.34 ms)의 1/5, FisherRF(22.03 ms)의 1/22 이다.

핵심 기여

1. 2DGS 지도의 불확실성을 정량화하는 확률적 신뢰도 모델 — 각 2D Gaussian 의 명시적 법선을 기준으로 앞면/뒷면을 나눠 이진 베이즈 필터로 갱신한다.
2. 색·깊이·법선 잔차를 함께 반영해 시각 품질과 기하 품질을 동시에 고려하는 실시간 NBV 지표 2D GauSS-MI.
3. 증분 RGB-D 관측을 받아 실시간으로 도는 온라인 2DGS 매핑 파이프라인 + 위 둘을 묶은 완결형 능동 재구성 시스템.
4. Replica 8장면 × 3회 반복으로 ActiveGS / GauSS-MI / FisherRF 세 베이스라인과 비교한 실험.

1. 배경과 문제 정의

능동 재구성이란 관측 순서가 미리 주어지는 일반 재구성과 달리, 로봇이 센서 궤적을 스스로 제어해 정보량이 큰 관측을 모아 가며 3D 표현을 완성하는 문제다. 핵심은 "지금 지도 상태에서 어디를 보러 가는 것이 가장 이득인가"를 재는 NBV 기준을 어떻게 정의하느냐다.

계보를 정리하면 이렇다. 초기에는 복셀 그리드·메시·점군 같은 가벼운 기하 표현 위에서 기하 정보 이득(표면 커버리지, 기하 불확실성, frontier)으로 시점을 골랐다. 이 기준들은 탐사에는 좋지만 복원된 장면의 시각 충실도를 직접 반영하지 못한다. NeRF 와 3DGS 가 등장한 뒤에도 초기 방법들은 여전히 커버리지 기준을 썼고, 이후 신경망으로 시점별 불확실성을 추정하는 방법(ActiveNeRF, NeurAR)이 나왔으나 학습 데이터와 불확실성 추정기 품질에 성능이 묶인다. 3DGS 는 장면을 공간상에 흩어진 Gaussian 으로 명시적으로 들고 있어 불확실성을 더 직접 평가할 수 있고(FisherRF, 선행 GauSS-MI), 이 논문은 그 노선 위에 있다.

왜 3DGS 가 아니라 2DGS 인가

저자들이 든 이유는 네 가지다. ① 3D Gaussian 의 부피형 래디언스 표현은 얇은 표면에 맞지 않고, ② 표면 법선을 자체적으로 제공하지 않으며, ③ 3D 타원체 래스터화는 다시점 일관성이 없어 보는 방향마다 2D 교차 평면이 달라진다. NBV 평가는 "아직 보지 않은, 그것도 비스듬한 후보 시점"에서 품질을 예측하는 일이라 이 ③이 치명적이다. 2DGS 는 perspective-correct ray-splat intersection 으로 다시점 일관 기하를 보장한다. ④ 같은 2D Gaussian 계열인 Gaussian Surfels 는 학습 중 외부 법선 prior 와 부피형 후처리가 필요한 반면 2DGS 는 기하 정규화만 넣으면 되어 RGB-D 능동 재구성에 더 맞는다. 또 3DGS·Gaussian Surfels 는 원근 투영을 아핀 근사로 처리해 Gaussian 중심에서 멀어질수록 정확도가 떨어진다.

직접적인 출발점은 같은 1저자의 선행 연구 GauSS-MI(RSS 2025)다. 그 논문은 3DGS 위에서 렌더링 잔차로 확률 모델을 만들고 Shannon 상호정보량을 최대화해 NBV 를 골랐는데, 시점 의존 신뢰도를 월드 좌표계의 수평 4분면(quadrant) 단위로 정의했다. 그러면 개별 Gaussian 이 각자 어느 쪽을 향하고 있는지를 반영할 수 없다. 2DGS 는 Gaussian 마다 명시적 법선을 들고 있으니, 그 법선을 기준으로 신뢰도를 정의하면 "이 면을 어느 쪽에서 봤는가"를 Gaussian 단위로 따질 수 있다 — 이것이 이 논문의 출발 착상이다.

2. 방법

2.1 2DGS 복습 — 무엇을 들고 있나

2D Gaussian 은 국소 접평면 위에 정의된다. 중심 $\mu$, 직교하는 접선 벡터 $t_u, t_v$ 와 스케일 $s_u, s_v$ 를 갖고, 단위 법선은 $n = t_u \times t_v$, 회전행렬은 $R = [t_u, t_v, n]$ 이다. 여기에 불투명도 $\alpha$ 와 색 $c$ 가 붙는다. 계산량을 줄이려고 구면 조화 함수(spherical harmonics)는 빼서, 색은 시점 독립(view-independent)이다.

시점 $\sigma$ 에서 렌더링할 때는 각 광선과 만나는 Gaussian 들을 깊이 순으로 정렬해 앞에서 뒤로 합성한다. Gaussian $i$ 의 누적 투과도(cumulative transmittance) 는

$$T^{[i]} = \alpha^{[i]} \prod_{m<i}\left(1-\alpha^{[m]}\right)$$

이고, 색·깊이·법선 이미지는 각각 $C=\sum_i c^{[i]}T^{[i]}$, $D=\sum_i d^{[i]}T^{[i]}$, $N=\sum_i n^{[i]}T^{[i]}$ 로 계산된다. $d^{[i]}$ 는 ray-splat 교차점의 깊이다. 이 $T^{[i]}$ 가 뒤에서 "이 관측이 이 Gaussian 에 얼마나 책임이 있는가"의 가중치로 재활용된다 — 가려졌거나 화면 밖인 Gaussian 은 $T=0$ 이므로 자동으로 갱신에서 빠진다.

2.2 온라인 증분 2DGS 매핑 (III-B)

매 시각 $k$ 에 로봇은 추정된 카메라 포즈 $\sigma_k$ 에서 컬러 이미지 $\hat{C}_k$ 와 깊이 이미지 $\hat{D}_k$ 를 얻는다. 파이프라인은 네 단계다.

  1. Gaussian 추가. 관측 깊이를 역투영(back-projection)해 새 Gaussian 의 중심을 초기화한다. 법선 $n$ 은 국소 깊이 기울기(local depth gradient) 에서 추정하고, 관측 카메라 쪽을 향하도록 방향을 맞춘다.
  2. 중복 제거. 지도 크기를 묶어두기 위해 해시 복셀 그리드(hash voxel grid) 를 유지하고, 새로 초기화된 Gaussian 의 중심이 기존 Gaussian 으로부터 거리 $\gamma$ 안에 있으면 기각한다. ($\gamma = 5$ cm. 이 기각 규칙이 10.4 MB 라는 모델 크기의 직접적 원인이다.)
  3. 최적화 스케줄. 갱신된 지도를 새 관측 프레임에 대해 $K_{new}=60$ iteration 최적화하고, 이어서 이전에 수집한 프레임들을 무작위로 재생(replay)해 $K_{replay}=40$ iteration 더 돈다. replay 는 이미 복원된 영역이 새 프레임 학습으로 망가지는 것을 막는 장치다. 즉 프레임 하나당 총 100 iteration 이 고정으로 들어간다.
  4. 손실. 렌더링 손실 + 2DGS 의 기하 정규화 둘.

기하 정규화 첫 번째는 깊이 왜곡 손실(depth distortion loss) 로, 광선 위의 Gaussian 들을 표면 주변 얇은 띠로 모은다.

$$\mathcal{L}_{Ddist} = \sum_i \sum_{m<i} T^{[i]}T^{[m]}\left| d^{[i]} - d^{[m]} \right|$$

두 번째는 법선 일관성 손실(normal consistency loss) 로, splat 법선을 렌더링된 깊이에서 추정한 표면 기하 $N_D$ 에 맞춘다.

$$\mathcal{L}_{Nconst} = 1 - N^{\top}N_D$$

최종 학습 손실은 가중합이다.

$$\mathcal{L} = \mathcal{L}_C + \lambda_{t,D}\mathcal{L}_D + \lambda_{t,Dd}\mathcal{L}_{Ddist} + \lambda_{t,Nc}\mathcal{L}_{Nconst}$$

$\mathcal{L}_C$ 는 L1 과 D-SSIM 을 섞은 색 렌더링 손실, $\mathcal{L}_D$ 는 L1 깊이 렌더링 손실이다. 가중치는 $\lambda_{t,D}=5.0$, $\lambda_{t,Dd}=1.0$, $\lambda_{t,Nc}=0.05$.

구현 기반

온라인 재구성 모듈은 2DGS-SLAM(Zhong 외, "Globally Consistent RGB-D SLAM with 2D Gaussian Splatting", T-RO 2026) 위에 올려 능동 재구성용으로 개조·확장한 것이다. 거기에 더해 2DGS 래스터라이저를 구현 수준에서 최적화해 속도를 올렸다고만 적고, 구체적인 최적화 내용은 밝히지 않는다.

2.3 2D Gaussian Splat 신뢰도 — 베이즈 모델링과 갱신 (IV-A-1)

각 Gaussian $i$ 에 대해 "이 Gaussian 이 재구성에 신뢰할 만한가"를 나타내는 확률변수 $r^{[i]}$ 를 둔다. 신뢰도 확률 $P(r^{[i]}) \in (0,1)$ 은 승산(odds) $o^{[i]} \in (0,+\infty)$ 또는 로그 승산(log odds) $l^{[i]} \in (-\infty,+\infty)$ 로 바꿔 쓴다.

$$l^{[i]} := \log\left(o^{[i]}\right) := \log\left(\frac{P(r^{[i]})}{1-P(r^{[i]})}\right)$$

장면에 대한 사전 정보가 없다고 가정하므로 초기값은 $P_0(r^{[i]}) = 0.5,\ \forall i \in \mathcal{G}$ (즉 $l_0 = 0$)이고, 신뢰도는 Gaussian 끼리 독립이라고 가정한다. 그러면 관측열 $Z_{1:k}$ 에 대한 사후확률은 이진 베이즈 필터(binary Bayesian filter) 로 재귀 갱신된다.

$$o^{[i]}(Z_{1:k}) = \delta^{[i]}(Z_k)\, o^{[i]}(Z_{1:k-1})$$

$\delta^{[i]}(Z_k)$ 는 역 센싱 모델(inverse sensing model)의 승산비 로, $k$ 번째 관측이 Gaussian $i$ 에 대해 제공하는 신뢰 증거다. 선행 GauSS-MI 를 따라 재구성 손실 $L_k$ 로 정의한다.

$$\delta^{[i]}_k = \left(\lambda_L L_k\right)^{-\lambda_T T^{[i]}} \quad\Longrightarrow\quad l^{[i]}_{1:k} = -\lambda_T T^{[i]}\log\left(\lambda_L L_k\right) + l^{[i]}_{1:k-1}$$
이 식을 말로 풀면

"재구성 손실의 로그를, 각 Gaussian 의 누적 투과도 $T^{[i]}$ 에 비례해 나눠 더한다." 손실이 작으면($\lambda_L L_k < 1$) $\log$ 가 음수라 $l$ 이 올라가고, 손실이 크면 $l$ 이 내려간다. $\lambda_L=1.0$ 이므로 사실상 "손실이 1보다 작으냐"가 분기점이다. 중요한 따름정리: 한 번도 보지 않은 Gaussian($l=0$, $P=0.5$)보다 "봤는데 잘 안 맞는" Gaussian 이 더 낮은 신뢰도($P<0.5$)를 가질 수 있다. 즉 이 값은 단순한 "관측 횟수 카운터"가 아니라 잔차를 누적한 양이다.

2.4 ★ 양면 신뢰도(two-sided reliability) — 이 논문의 핵심 (IV-A-2)

위 갱신식은 Gaussian 하나에 신뢰도 하나를 준다. 그런데 한쪽에서는 잘 복원되는 Gaussian 이 반대쪽에서는 못 믿을 수 있으므로, 신뢰도는 본질적으로 방향 의존이다. 선행 GauSS-MI(3DGS)는 이를 월드 좌표계 수평 방향 4분면 신뢰도로 처리했는데, 저자 표현으로는 "개별 Gaussian 의 고유한 방향을 거의 수용하지 못한다". 2DGS 는 Gaussian 마다 명시적 법선이 있으니, 그 법선이 곧 "이 면이 어느 쪽을 보고 있는가" 의 기준이 된다. 그래서 앞면/뒷면 두 개의 신뢰도를 둔다.

$$P(r^{[i]}) = \left(\,P(r^{[i]}_f),\ P(r^{[i]}_b)\,\right)$$
  • 앞면(front) = Gaussian 법선 방향 = 그 Gaussian 이 처음 관측된 시점이 있는 쪽. (2.2 에서 법선을 "관측 카메라 쪽을 향하도록" 초기화했기 때문에 정의상 그렇게 된다.)
  • 뒷면(back) = 그 반대 방향.
  • 저자의 단서: "일반적으로는 앞면 신뢰도만 의미가 있고, 뒷면 신뢰도는 양쪽에서 올바르게 관측될 수 있는 얇은 구조에서 추가로 의미를 갖는다."

어느 면을 봤는지 판정하고 관측 가중치를 재기 위해, Gaussian $i$ 에서 카메라 포즈 $\sigma_k$ 를 향하는 단위 벡터 $d^{[i]}_k = (\sigma_k - \mu^{[i]})/\lVert \sigma_k - \mu^{[i]}\rVert$ 를 정의하고, 입사각 $\theta$ 와 관측 품질 가중치 $w$ 를 둔다.

$$w^{[i]}_k = \cos\theta^{[i]}_k = d^{[i]}_k \cdot n^{[i]}$$

$w=1$ 은 앞면 정면 관측, $w=0$ 은 모서리에서 스치는 관측(edge-on), $w<0$ 은 뒷면 관측이다. 갱신할 로그 승산은 $w$ 의 부호로 고른다.

$$l^{[i]}_{k,obs} = \begin{cases} l^{[i]}_{k,f}, & w^{[i]}_k > w_{min}\\[2pt] l^{[i]}_{k,b}, & w^{[i]}_k < -w_{min}\\[2pt] \text{갱신 건너뜀}, & \left| w^{[i]}_k \right| \le w_{min} \end{cases}$$

게이트 $w_{min}=0.1$ 은 거의 모서리로 스친 Gaussian 을 갱신에서 제외한다. 선택된 면의 로그 승산은 픽셀별 재구성 손실 $L^{[j]}_k$ 로 갱신된다.

$$l^{[i]}_{k,obs} = \lambda_T \left| w^{[i]}_k \right| \sum_j -\log\left(\lambda_L L^{[j]}_k\right) T^{[i,j]}$$

$T^{[i,j]}$ 는 픽셀 $j$ 에서의 Gaussian $i$ 누적 투과도라서, Gaussian $i$ 가 실제로 기여한 픽셀만 합에 들어간다. 가려졌거나 화면 밖인 Gaussian 은 아무 갱신도 받지 않는다.

여기 쓰이는 재구성 손실 $L$ 은 색·깊이·법선 불일치를 합친 것이다.

$$L = \mathcal{L}_C + \lambda_{r,D}\mathcal{L}_D + \lambda_{r,Nr}\mathcal{L}_{Nrend}, \qquad \mathcal{L}_{Nrend} = 1 - N^{\top}\hat{N}$$

$\hat{N}$ 은 관측 깊이에서 추정한 법선이다. 2.2 의 $\mathcal{L}_{Nconst}$ 와 혼동하면 안 된다 — 전자는 학습 중 렌더링 법선을 렌더링 깊이에 맞추는 자기 일관성 정규화이고, 후자(여기)는 렌더링 법선을 실제 관측 기하와 비교하는 신뢰도 추정용 잔차다. 가중치는 $\lambda_{r,D}=3.0$, $\lambda_{r,Nr}=0.15$, $\lambda_T = 1.2$.

왜 이렇게 설계했나

신뢰도를 "본 횟수"가 아니라 색+깊이+법선 잔차로 재면, 하나의 스칼라 안에 시각 품질과 기하 품질이 함께 들어간다. 그리고 그 스칼라를 Gaussian 의 법선 기준 앞/뒤로 쪼개 두면, NBV 평가 때 "이미 정면에서 충분히 본 면"과 "아직 그쪽에서 본 적 없는 면"을 Gaussian 단위로 구분할 수 있다. 월드 4분면으로는 불가능한 해상도다.

2.5 2D GauSS-MI — 후보 시점 평가 (IV-B)

과거 관측 $Z_{1:k-1}$ 이 주어졌을 때, 다음 시점은 상호정보량 $I(r;z)$ 를 최대화하도록 고른다. 픽셀별 측정이 독립이라고 가정하면 픽셀 $j$ 와 Gaussian $i$ 로 분해된다.

$$I(r;z) = \sum_j \sum_i I(r^{[i]}; z^{[j]})\, T^{[i,j]} = \sum_j P(z^{[j]})\sum_i f\!\left(\delta^{[i]}(Z),\, o^{[i]}_{1:k-1}\right) T^{[i,j]}$$

$P(z^{[j]})$ 는 센서 품질에만 의존하는 측정 사전확률(measurement prior), $f$ 는 정보 이득 함수다.

$$f(\delta, o) = \frac{o}{o+\delta^{-1}}\log\left(\frac{o+1}{o+\delta^{-1}}\right)$$

후보 시점은 아직 관측이 없으므로 역 센싱 모델을 기댓값으로 근사해야 한다. "기대되는 재구성은 신뢰할 만하다"고 가정해 $L_k = 0$ 으로 두면 $\delta^{-1}=0$ 이 되고, 정보 이득 함수가 아주 깔끔해진다.

$$f^{[i]} = \log\left(\frac{o^{[i]}+1}{o^{[i]}}\right) = -\log\left(P(r^{[i]})\right)$$

마지막으로 신뢰도 갱신과 같은 방식으로 방향 가중치 $|w^{[i]}_n|$ 을 곱하고, 양면 신뢰도 중 해당 면을 골라 쓴다. 최종 2D GauSS-MI 는

$$I_n(r;z) = \sum_j P(z^{[j]})\sum_i -\left|w^{[i]}_n\right| \log\left(P(r^{[i]}_{n,obs})\right) T^{[i,j]}$$

세 요소가 곱으로 들어간다 — 측정 잡음 $P(z^{[j]})$, 현재 신뢰도 $-\log P$, 후보 시점과 법선의 방향 불일치 $|w|$. 시뮬레이션에서는 시뮬레이터가 정답 관측을 준다고 보고 $P(z^{[j]})\approx 1$ 로 두며, 실제 배치에서는 선행 GauSS-MI 를 따라 카메라 잡음 모델에서 추정할 수 있다고만 적는다.

숫자 감각

$-\log P$ 는 $P=0.5$(미관측)에서 $\log 2 \approx 0.693$, $P\to 1$(충분히 잘 본 면)에서 $\to 0$, $P<0.5$(봤는데 잔차가 컸던 면)에서 $0.693$ 보다 커진다. 즉 이 지표는 "안 본 곳"보다 "봤는데 잘 안 맞은 곳"을 더 세게 끌어당긴다. 능동 재구성에서 이게 성립하려면 잔차가 "정보 부족"에서 와야 하는데, 뒤에서 보듯 이 가정이 항상 성립하지는 않는다.

먼저 사실관계

이 논문에는 Limitations 절도, Future Work 절도 없다. 결론은 기여 요약으로만 끝난다. 아래 목록 중 ◆ 는 본문에 명시적으로 적힌 단서이고, 나머지는 읽으면서 드러난 것이다.

  • ◆ 뒷면 신뢰도는 "일반적으로 의미가 없다". 저자 스스로 "일반적으로는 앞면 신뢰도만 의미가 있고, 뒷면은 얇은 구조에서 추가로 의미를 갖는다"고 적는다. 논문의 핵심 기여를 저자가 직접 조건부로 좁혀 놓은 셈이고, 그 조건에서 얼마나 이득인지를 보이는 실험은 없다.
  • ◆ 측정 사전확률 $P(z^{[j]})$ 를 1 로 놓았다. 시뮬레이터가 정답 관측을 준다는 가정이다. 실세계에서는 카메라 잡음 모델로 추정해야 한다고 적어 두었을 뿐, 실세계 실험이 하나도 없다. Habitat/Replica 시뮬레이션이 전부다.
  • 구면 조화 함수를 뺐다 — 색이 시점 독립이다. 반사·광택이 강한 실세계 장면에서는 색 잔차가 "복원 불충분" 때문이 아니라 "표현력 부족" 때문에 커질 수 있고, 그러면 신뢰도가 영구히 낮게 유지돼 NBV 가 같은 곳을 반복해서 보러 갈 위험이 있다.
  • 포즈 문제를 다루지 않는다. 본문은 "추정된 카메라 포즈 $\sigma_k$"라고만 쓰고, 포즈가 시뮬레이터 정답인지 2DGS-SLAM 의 추적 결과인지 명시하지 않는다. 추적 오차 지표(ATE 등)는 보고되지 않으며, 포즈 오차가 신뢰도 갱신에 어떻게 섞여 들어가는지에 대한 논의도 없다.
  • ablation 전무. 3.3 끝에서 적은 대로, 설계 선택 하나하나의 기여를 분리한 실험이 없다. 성능 향상이 양면 신뢰도에서 온 것인지, 2DGS 표현 자체에서 온 것인지, 혹은 $\mathcal{L}_{Nrend}$ 를 신뢰도에 넣은 것에서 온 것인지 구분할 수 없다.
  • ActiveGS 비교 조건이 비대칭이다. 저자들이 투명하게 밝히긴 했지만, ActiveGS 만 자기 플래너를 쓰고 그 플래너가 쿼드로터로 실현 불가능한 궤적을 낸다. "같은 후보 집합에서의 시점 선택 기준 비교"는 GauSS-MI·FisherRF 에 대해서만 성립한다.
  • 신뢰도 독립 가정. Gaussian 끼리 신뢰도가 독립이라고 가정하는데, 같은 표면을 덮는 이웃 Gaussian 들은 당연히 상관되어 있다. 이 때문에 MI 가 실제보다 과대평가될 수 있으나 논의되지 않는다.

5.1 ★ 양면 신뢰도의 정확한 정의 — 무엇을 받고 어떻게 갱신하나

  • [논문] 관측으로 받는 것은 "픽셀별 재구성 손실 이미지"다. 갱신식은 $l^{[i]}_{k,obs} = \lambda_T|w^{[i]}_k|\sum_j -\log(\lambda_L L^{[j]}_k) T^{[i,j]}$ 이고, $L^{[j]} = \mathcal{L}_C + 3.0\,\mathcal{L}_D + 0.15\,\mathcal{L}_{Nrend}$ 이다. 즉 렌더링 색 vs 관측 색, 렌더링 깊이 vs 관측 깊이, 렌더링 법선 vs 관측 깊이에서 추정한 법선 세 잔차의 가중합이다. 포즈도, 기하 covariance 도, Fisher 정보도 아니다.
  • [논문] 갱신은 이진 베이즈 필터(로그 승산 덧셈)다. $l_{1:k} = l_k + l_{1:k-1}$, 초기 $P_0(r)=0.5$($l=0$). 감쇠항도, 망각 계수도 없다 — 단조 누적이다.
  • [논문] front/back 을 가르는 기준은 $w = \cos\theta = d\cdot n$ 의 부호이고, $|w| \le w_{min}=0.1$ 이면 갱신을 건너뛴다. $d$ 는 Gaussian 중심 → 카메라 방향, $n$ 은 2DGS 의 명시적 법선이다. 이 부호 판정 하나가 전부다 — "앞면을 보는가"는 가시성(visibility) 판정이 아니라 순수한 방향 내적 판정이다. 가시성은 별도로 $T^{[i,j]}$ 가 담당한다(가려지면 0).
  • [논문] 앞면의 정의는 "법선 방향" = "최초 관측 시점이 있던 쪽"이다. 2.2 에서 새 Gaussian 의 법선을 관측 카메라 쪽을 향하도록 초기화하기 때문에, 모든 Gaussian 은 관측으로부터 태어나고 그 태어난 쪽이 앞면이 된다.
  • [논문+추론] 뒷면 신뢰도의 초기값은 0.5 이고, 갱신 조건은 $w < -0.1$ 즉 "실제로 뒤에서 본 관측이 들어왔을 때"뿐이다. 원문은 $P_0(r^{[i]})=0.5\ \forall i$ 를 양면 분리 이전에 선언하고 이후 $(P(r_f), P(r_b))$ 로 쪼개므로, 두 면 모두 0.5 에서 출발한다고 읽는 것이 자연스럽다(명시적 재선언은 없다 — [추론]).
그래서 루틴의 ①번 주장은?

[논문] "뒷면 신뢰도 = 아직 관측되지 않은 면"은 사실이다. 뒷면은 정의상 태어날 때 관측된 적이 없고, 뒤에서 본 관측이 들어오기 전까지 $P_b = 0.5$ 로 고정된다. MI 식에서 $-\log 0.5 = 0.693$ 의 일정한 이득으로 남아 "이 면의 반대쪽을 보러 가라"는 신호가 된다. [추론] 다만 "prior 가 만들었지만 아직 관측되지 않은 면"은 아니다 — 이 논문에는 prior 가 없고, 뒷면은 관측으로 태어난 Gaussian 의 반대쪽일 뿐이다. 두 개념은 기하학적으로 겹치지만 인식론적으로 다르다: 전자는 "존재한다고 가정된 면", 후자는 "존재가 관측으로 확인된 면의 반대쪽"이다.

5.2 선행 GauSS-MI(3DGS)와 무엇이 다른가 — 원문 근거 있음

  • [논문] 있다. 두 군데에 명시적으로 적혀 있다. 2장 끝: "GauSS-MI 는 시점 의존 신뢰도를 월드 프레임의 수평 4분면(four horizontal quadrants in the world frame) 위에 정의하는데, 이는 개별 Gaussian 의 방향을 명시적으로 고려하지 못한다. 2DGS 의 명시적 표면 법선은 각 프리미티브의 고유한 방향(intrinsic orientation) 을 기준으로 신뢰도를 정의할 자연스러운 참조를 제공한다." IV-A-2 에서 거의 같은 문장이 반복된다.
  • [논문] 베이즈 뼈대 자체는 선행 GauSS-MI 를 그대로 가져왔다. 역 센싱 모델 $\delta = (\lambda_L L)^{-\lambda_T T}$ 는 인용 [7]로 명시되고, MI 분해와 정보 이득 함수 $f(\delta,o)$ 도 동일 계열이다. 새로운 것은 ① 4분면 → per-Gaussian 법선, ② 단일 신뢰도 → 앞/뒤 2채널, ③ $|w|$ 방향 가중치, ④ 재구성 손실에 법선 잔차 $\mathcal{L}_{Nrend}$ 추가, 네 가지뿐이다.
  • [추론] 신규성의 크기를 정직하게 보면, 이 논문은 "같은 확률 모델을 더 좋은 기하 표현 위로 옮기고 방향 해상도를 올린 것"이다. 그래서 1저자가 같은 사람이고 ablation 이 없다는 점이 함께 설명된다.

5.3 ★★ 이 신뢰도는 "불확실성"인가 "prior–관측 불일치"인가

판정

[논문] 이 값은 파라미터 불확실성이 아니라 "현재 지도의 렌더링 vs 관측" 잔차의 누적이다. FisherRF 가 Fisher 정보 행렬(= 파라미터 공분산)을 쓰는 것과 대비하면 분명하다. 이 논문의 $r^{[i]}$ 는 "이 Gaussian 이 재구성에 신뢰할 만한가"라는 이진 잠재변수이고, 그 증거는 전적으로 렌더–관측 잔차다. 그런 뜻에서 불일치(disagreement)에 가깝다.

[논문] 그러나 그 불일치의 두 피연산자는 "현재 2DGS 지도"와 "센서 관측"이다. generative prior 는 이 논문에 존재하지 않는다. 전체 본문 어디에도 diffusion/generative/image-to-3D prior 가 없고, 모든 Gaussian 은 관측 깊이의 역투영으로 태어난다. 1절에서 "장면에 대한 사전 정보가 없다고 가정하므로 $P_0 = 0.5$" 라고 명시적으로 선언하기까지 한다. 즉 루틴이 추정한 대로, 이 세팅에는 "prior 와 관측의 불일치"를 잴 대상 자체가 없다.

[추론] 그런데 이게 C1 방어에 유리한가 불리한가 — 양쪽 다다. 정리하면:

  • 유리한 점: C1 의 핵심 주장("prior 와 관측이 충돌할 때 무엇을 근거로 신뢰를 재배분하는가")은 이 논문이 다루지 않는다. 이 논문의 신뢰도는 지도가 관측에 얼마나 수렴했는가를 재며, 그 지도는 같은 관측으로 프레임당 100 iteration 학습된다. 즉 잔차는 최적화가 적극적으로 0 으로 밀어 내리는 양이다. "아직 덜 봤다"와 "가설이 틀렸다"를 구분할 장치가 원리적으로 없다.
  • 불리한 점: "per-Gaussian 에 잔차 기반 베이즈 신뢰도를 붙이고, Gaussian 법선으로 방향을 나눠, 미관측 면을 0.5 로 남겨 둔다"는 형식(formalism) 은 이 논문이 2DGS 위에서 이미 썼다. C1 을 "per-Gaussian 관측 누적 통계를 신호로 쓴다"로 서술하면 신규성이 서지 않는다. HIPPo 가 "prior 를 freeze 하지 않는다"를 선점했듯, 2D GauSS-MI 는 "per-2D-Gaussian 양면 베이즈 신뢰도"라는 신호의 형식을 선점했다.
C1 정의 문장에 반영할 것

[추론] "불일치를 측정한다"만으로도 부족하다. 어떤 두 양 사이의 불일치인지를 정의에 박아야 한다. 2D GauSS-MI 의 신호는 $\text{render}(\mathcal{G}) \leftrightarrow \text{observation}$ 이고, C1 의 신호는 $\text{prior-hypothesized geometry} \leftrightarrow \text{observation}$ 이어야 한다. 전자는 최적화가 지우는 양이고 후자는 지워지지 않는 양이다 — 이 차이가 C1 의 기여 문장이다.

5.7 판정 — 이 신뢰도를 C1 중재 신호로 그대로 채택할 수 있는가

결론: 형식은 채택, 의미는 재정의. "그대로"는 안 된다.

[추론] 채택할 수 있는 것은 표현 방식이다 — per-2D-Gaussian 로그 승산 2채널(front/back), $w=d\cdot n$ 부호로 면 선택, $|w|$ 로 가중, $T^{[i,j]}$ 로 가시성 처리, 잔차 로그를 splat 에 누적. 이건 싸고(렌더링 1회), 미분 불필요하고, 2DGS 와 자연스럽게 맞물린다. 그대로 쓸 수 없는 것은 "신뢰도가 무엇을 재는가"의 의미다.

[추론] generative prior 가 없는 세팅에서 정의된 양을 prior 가 있는 세팅으로 옮길 때 깨지는 것 넷.

  1. front/back 의 기준점이 사라진다. 이 논문에서 앞면은 "최초 관측 시점이 있던 쪽"이다. SAM3D prior 로 태어난 Gaussian 에는 최초 관측 시점이 없다. 대체재는 생성 메시의 바깥 방향 법선인데, 그러면 "앞면 = 물체 바깥쪽"이 되어 의미가 "관측된 쪽"에서 "물체 외부를 향한 쪽"으로 바뀐다. 그 결과 뒷면 신뢰도는 폐곡면 물체에서는 영원히 가려져 $T\approx 0$ 이 되고 죽은 채널이 된다. 즉 물체 단위 폐곡면 세팅에서는 양면 구조가 거의 무의미해진다 — 저자 본인이 "뒷면은 얇은 구조에서만 의미 있다"고 적은 것과 정확히 같은 이유다. 연욱님 세팅에서 쓸 수 있는 것은 사실상 단면(front) 신뢰도 + $|w|$ 가중치다.
  2. $P_0 = 0.5$ 가 prior 를 표현하지 못한다. 이 모델에는 "관측으로 태어난 Gaussian"과 "prior 로 가정된 Gaussian"을 구분하는 자리가 없다. 둘 다 0.5 에서 시작한다. C1 에는 prior 출신 Gaussian 에 다른 초기 로그 승산(예: $l_0 < 0$, 또는 prior 신뢰도 채널 별도 유지)을 주는 확장이 필수다. 다행히 베이즈 뼈대가 로그 승산 덧셈이라 초기값만 바꾸면 되는 가장 싼 확장이다.
  3. 잔차가 최적화로 지워진다 — 이게 가장 치명적이다. 이 논문은 프레임당 100 iteration 으로 지도를 관측에 맞춘 뒤 잔차를 잰다. prior 가 틀렸더라도 Gaussian 이 관측 쪽으로 끌려가 버리면 잔차는 작아지고 신뢰도는 올라간다 — "prior 가 틀렸다"는 사건이 측정되기 전에 소멸한다. C1 에서는 잔차를 최적화 전(또는 prior 파라미터를 잠시 고정한 상태)에서 재야 한다. 구체적으로는 "새 프레임이 들어온 직후, $K_{new}$ 최적화 이전의 렌더링 잔차"를 중재 신호로 쓰고, 최적화 후 잔차는 쓰지 않는 설계가 자연스럽다. 이 한 줄이 2D GauSS-MI 와 C1 을 가르는 메커니즘 차이가 된다.
  4. 단조 누적은 "충돌 감지"에 부적합하다. 로그 승산에 망각이 없으므로, 초반에 잘 맞던 면이 나중에 가려짐·포즈 드리프트로 어긋나기 시작해도 누적된 높은 신뢰도가 한참 버틴다. C1 처럼 국소적으로 신뢰를 재배분하려면 최근 잔차에 가중을 주는 창(window)이나 감쇠가 필요하다. 이 논문은 능동 재구성이라 "본 곳은 계속 좋아진다"는 가정이 성립해 문제가 드러나지 않지만, 가림이 들어오는 HO3D/YCBInEOAT 에서는 성립하지 않는다.
그래서 논문에 쓸 문장

[추론] 루틴의 제안("두-면 reliability 를 그대로 채택한 뒤 용도 차이를 선언")은 절반만 맞다. "용도 차이"(NBV 선택 vs prior–관측 중재)만 선언하면 심사자는 "같은 신호를 다른 곳에 썼다"로 읽고 기여를 깎는다. 안전한 서술은 이렇다 — "2D GauSS-MI 는 render–observation 잔차를 최적화 수렴도의 대리 변수로 쓴다. 우리는 같은 per-Gaussian 로그 승산 형식을 쓰되, (a) prior 출신 Gaussian 에 구분된 초기 신뢰도를 부여하고, (b) 잔차를 최적화 이전에 측정해 prior 가설과 관측의 충돌을 보존하며, (c) 그 측정으로 prior 항과 관측 항의 손실 가중치를 Gaussian 단위로 재배분한다." 즉 신호의 형식은 인용하고, 측정 시점·초기값·소비처 세 가지를 바꾸는 것이 기여다. 그리고 2D GauSS-MI 는 관련 연구가 아니라 "신호 설계의 선행"으로 명시 인용해야 한다 — 숨기면 선점당한 것으로 보인다.

[추론] 추가 실무 메모 두 가지. ① 이 논문에 ablation 이 없다는 사실은 역설적으로 기회다 — "front/back 분리가 실제로 도움이 되는가"는 아직 아무도 측정하지 않았으므로, 연욱님 쪽에서 물체 단위 세팅의 ablation 으로 보고하면 그 자체로 작은 기여가 된다(그리고 1번 항목의 예상대로 "폐곡면에서는 도움이 안 된다"가 나오면 그것도 보고 가치가 있다). ② $\mathcal{L}_{Nrend} = 1 - N^\top \hat N$ (렌더링 법선 vs 관측 깊이 법선)은 C1 중재 신호의 구성 성분으로 바로 쓸 만하다 — 색 잔차는 조명·재질에 흔들리고 깊이 잔차는 스케일에 의존하지만, 법선 각도 잔차는 prior 가 만든 면의 방향이 틀렸는지를 가장 직접적으로 잡는다. 가중치 0.15 로 작게 쓴 것은 이 논문이 장면 단위라 그렇고, 물체 단위에서는 더 키울 여지가 있다.

6. 정리와 시사점

한 문장으로

선행 GauSS-MI 의 상호정보량 틀을 2DGS 위로 옮기면서, 월드 4분면 신뢰도를 Gaussian 법선 기준 앞면/뒷면 2채널 베이즈 신뢰도로 바꾼 능동 장면 재구성 시스템. 덕분에 시각·기하 품질을 동시에 끌어올리면서 후보 뷰 평가를 1.01 ms 로 줄였다.

가져갈 아이디어

  • 잔차를 splat 에 역투영하는 방식. 픽셀 손실의 로그를 $T^{[i,j]}$ 가중으로 Gaussian 에 누적하면, 가시성·가림 처리가 공짜로 따라온다($T=0$ → 갱신 없음). 별도의 가시성 판정 코드가 필요 없다.
  • 로그 승산 표현의 값싼 확장성. 신뢰도를 확률이 아니라 로그 승산으로 들고 있으면 갱신이 덧셈이고, 초기값·채널 수를 바꾸는 것만으로 모델을 확장할 수 있다. C1 신호를 설계할 때 이 표현을 기본형으로 쓸 만하다.
  • 복셀 해시 기반 Gaussian 추가 기각($\gamma$=5 cm). Gaussian 수 폭증을 막는 가장 단순한 장치. 모델 10.4 MB 와 Figure 4 의 평평한 평가 시간이 그 결과다.
  • 후보 평가를 궤적 계획 "뒤"에 두는 설계. 실현 불가능한 시점에 MI 계산을 낭비하지 않는다. ActiveGS 와의 비교에서 초반 열세를 감수하더라도 후반에 역전하는 근거가 된다.
  • 법선 각도 잔차를 품질 신호로 쓰기. $1-N^\top\hat N$ 는 색·깊이 잔차가 놓치는 "면의 방향이 틀림"을 직접 잡는다.

같이 보면 좋은 논문

  • 2DGS (Huang 외, SIGGRAPH 2024) — [본 논문이 직접 인용·채택] 지도 표현 그 자체. ray-splat intersection, depth distortion / normal consistency 정규화를 이 논문이 그대로 가져온다. 저장소 정리: 2DGS.
  • GauSS-MI (Xie 외, RSS 2025) — [본 논문이 직접 인용·비교] 같은 1저자의 3DGS 판. 베이즈 뼈대와 MI 식의 출처이며 Table III·V 의 베이스라인. 저장소에 정리 없음 — 읽을 가치가 가장 높은 후속 대상이다.
  • ActiveGS (Jin 외, RA-L 2025) / FisherRF (Jiang 외, ECCV 2025) — [본 논문이 직접 인용·비교] 각각 Gaussian Surfels + 복셀 지도 계열, Fisher 정보 계열 베이스라인.
  • 2DGS-SLAM (Zhong 외, T-RO 2026) — [본 논문이 직접 인용, 구현 기반] 온라인 매핑 모듈의 출처. 포즈 공동 최적화가 필요한 연욱님 백엔드에는 이쪽이 이 논문보다 더 직접적인 참조 구현이다.
  • ObjSplat (Li 외, T-ASE 2026) — [본 논문이 인용, 비교는 아님] Gaussian Surfels 기반 물체 단위 능동 재구성. back-face visibility 와 multi-view covisibility 로 기하 인식 시점 평가를 한다. 물체 단위라는 점에서 연욱님 세팅에 더 가깝다.
  • AURORA (CoRL 2026) — [본 논문에 교차 비교 근거 없음. 저장소 정리에서 가져온 대조] 저장소의 AURORA 정리는 같은 "능동 + 불확실성 기반 NBV" 문제를 인핸드 물체 단위에서 Ray-GPIS 불확실성으로 푼다. 대조점: AURORA 는 불확실성을 기하 표현(GPIS)의 사후 분산에서 뽑고, 이 논문은 렌더링 잔차의 베이즈 누적에서 뽑는다. "불확실성"이라는 같은 단어가 서로 다른 양을 가리키는 좋은 예다.
  • HIPPo — [본 논문에 교차 비교 근거 없음. 저장소 정리에서 가져온 대조] HIPPo 정리와 묶어 읽으면 C1 의 지형이 선명해진다. HIPPo 는 "prior 를 관측으로 고친다"는 문제 설정을, 2D GauSS-MI 는 "per-Gaussian 양면 베이즈 신뢰도"라는 신호 형식을 각각 선점했다. C1 에 남은 자리는 그 신호를 언제·무엇 사이에서 측정해 어떻게 소비하는가다.

용어 정리

능동 재구성 (active reconstruction)
관측 순서가 미리 주어지지 않고, 로봇이 센서 궤적을 스스로 제어해 정보량 큰 관측을 모아 가며 3D 표현을 완성하는 문제.
NBV (next-best-view)
현재 지도 상태에서 다음에 관측하면 가장 이득이 큰 시점. 능동 재구성의 핵심 결정 문제.
2DGS (2D Gaussian Splatting)
3D 타원체 대신 방향을 가진 평면 Gaussian 원반으로 장면을 표현. perspective-correct ray-splat intersection 으로 다시점 일관 기하를 보장하고 법선을 명시적으로 갖는다.
누적 투과도 (cumulative transmittance, $T^{[i]}$)
$\alpha^{[i]}\prod_{m<i}(1-\alpha^{[m]})$. 광선을 따라 앞쪽 Gaussian 들에 가려지고 남은 기여도. 이 논문에서는 "이 관측이 이 Gaussian 에 얼마나 책임이 있는가"의 가중치로 재사용된다.
로그 승산 (log odds, $l$)
$\log\frac{P}{1-P}$. 이진 베이즈 필터의 갱신을 곱셈에서 덧셈으로 바꿔 준다. $P=0.5 \Leftrightarrow l=0$.
역 센싱 모델 (inverse sensing model, $\delta$)
한 번의 관측이 잠재 상태에 주는 증거를 승산비로 표현한 것. 이 논문에서는 $\delta = (\lambda_L L)^{-\lambda_T T}$ 로 재구성 손실에서 만든다.
양면 신뢰도 (two-sided reliability)
각 2D Gaussian 에 앞면/뒷면 신뢰도 $(P(r_f), P(r_b))$ 를 따로 둔 것. 앞면은 법선 방향(=최초 관측 시점 쪽), 뒷면은 반대쪽. $w = d\cdot n$ 의 부호로 갱신할 쪽을 고른다.
관측 품질 가중치 ($w = \cos\theta$)
Gaussian→카메라 방향과 법선의 내적. 1 이면 정면, 0 이면 모서리 스침, 음수면 뒷면 관측.
측정 사전확률 (measurement prior, $P(z^{[j]})$)
센서 품질에만 의존하는 항. 시뮬레이션에서는 1 로 근사하고, 실세계에서는 카메라 잡음 모델로 추정해야 한다.
깊이 왜곡 손실 (depth distortion loss)
한 광선 위의 Gaussian 들을 표면 근처 얇은 띠로 모으는 2DGS 의 기하 정규화.
법선 일관성 손실 (normal consistency loss)
렌더링 법선을 렌더링 깊이에서 추정한 기하에 맞추는 자기 일관성 정규화. 신뢰도 갱신에 쓰이는 $\mathcal{L}_{Nrend}$(렌더링 법선 vs 관측 깊이 법선)와 구분해야 한다.
F-score
재구성 메시와 정답 메시 사이 5 cm 임계값에서의 정밀도·재현율 조화평균.
